# Compiler and gas benchmarks
Actual commands are generated by scripts/optimizer_matrix.py; raw outputs and result JSON are in evidence/. All six optimizer/viaIR combinations were attempted on identical protocol source and the 33-test AMM suite. No-IR 200/1000/10000 each FAIL with stack-too-deep; no gas/size result is invented for those builds.

| Runs / viaIR | Pair runtime / initcode bytes | Router runtime / initcode bytes | Factory runtime / initcode bytes | Tests |
|---|---|---|---|---|
| 200 / true | 7698 / 9785 | 4438 / 4582 | 10754 / 10780 | 33 PASS |
| 1000 / true | 8183 / 10270 | 4719 / 4863 | 11383 / 11409 | 33 PASS |
| 10000 / true | 9697 / 11784 | 6072 / 6217 | 13325 / 13351 | 33 PASS |

Initcode above excludes constructor ABI args: add 64 bytes for Pair and 32 for Router. All measured runtime sizes are below 24,576 bytes; actual initcode is below 49,152 bytes. Compiler warnings/results are retained per matrix log. A final independent-build comparison is recorded separately.

| Runs / viaIR | Factory deploy gas | Pair deploy gas | Router deploy gas | Router swap median gas in test distribution |
|---|---|---|---|---|
| 200 / true | 2371232 | 1818907 | 1036544 | 112427 |
| 1000 / true | 2499800 | 1916987 | 1093967 | 112227 |
| 10000 / true | 2909497 | 2235177 | 1376842 | 111260 |

Gas-report distribution includes fuzz, cold/warm calls and failed paths; its medians are not universal transaction quotes. Retain 1000 as the specified middle baseline: 200 reduces deploy size/cost; 10000 saves execution gas at substantial deployment/code-size cost. No globally optimal economic choice is claimed without expected pool activity. See ADR.

## Actual local transaction receipts, default 1000 / IR
Local Anvil normal ERC20 flow: Factory deploy 2,499,800; Router deploy 1,093,967; add (including first pair creation) 2,044,554; swap 107,197; complete user LP removal 107,251 gas. These are actual gasUsed in evidence/local-deployment.json, not script estimates. Swap input=10^16, initial reserves=10^18/10^18, actual output=9,871,580,343,970,612.
Reproduce using python3 scripts/local_smoke.py. No mainnet cost, Base L1 data fee or public deployment performance is inferred.

## Compiler caveat
0.8.28 has known optimized-IR compiler risk; see ../audit/compiler-review.md. Passing the matrix is not permission to publish this bytecode. After a patched compiler upgrade, replace these measurements with newly executed results.
